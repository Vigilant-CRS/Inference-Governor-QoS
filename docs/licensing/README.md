## Warum der Apache-Text nicht in `LICENSES/` liegt

Die BSL 1.1 nennt eine Change License: vier Jahre nach Veroeffentlichung jeder
Version geht diese Version in die Apache License 2.0 ueber. Der Text gehoert
deshalb ins Repository — nur ist heute **keine einzige Datei** Apache-lizenziert.

`LICENSES/` ist nach der REUSE-Spezifikation das Verzeichnis fuer die Lizenzen,
unter denen Dateien dieses Projekts *stehen*. Ein Text, den niemand
referenziert, ist dort ein Befund, und zwar zu Recht: er sieht sonst aus wie
eine Doppellizenzierung, die es nicht gibt.

Ihn stattdessen zu loeschen waere die schlechtere Antwort — dann fehlte der
Wortlaut der Lizenz, in die dieses Projekt uebergeht. Er liegt deshalb hier,
mit dieser Erklaerung daneben.
